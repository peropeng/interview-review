# Java 后端面试速读

**只剩 10 分钟：直接练下表。**  
还有 30 分钟：先看 [Java 八股](java.md)，再选两个最可能被追问的项目。最后合上文档，按「怎么做 → 为什么 → 失败怎么办」各说一遍。

## 临场先练这 7 问

| 常见问题 | 先说这几句 |
|---|---|
| 分期进度为什么查两次？ | 先用认证后的渠道身份查银行渠道号，再用渠道号和申请号查进度。两个查询对象不同；没配置、没记录、查询失败和审批拒绝要分开。 |
| 慢 SQL 为什么变快？ | 把月份格式化改成月初到下月初的范围，联合索引配合渠道、状态、时间和排序。改前改后对完整记录、字段和顺序。 |
| LangChain4j 在项目里怎么用？ | 配置模型，给审计、差异和修复定义 Java 调用接口；拿回结果后解析检查。程序控制阶段、确认和恢复，模型提供建议。 |
| 秒杀怎么防超卖？ | Lua 把库存和用户占用一起判断修改，MySQL 再用条件更新和唯一约束兜底。接口受理和正式订单确认分开。 |
| 消息重投或取消重试会不会多扣、多加？ | 数据库事务先提交，再提交 Kafka 消费位点；重复消费按订单号防重。取消按订单状态回补数据库，按原预扣流水释放 Redis，失败沿日志重试。 |
| 多个智能体（Agent）改代码怎么防冲突？ | 有依赖的先后做，共享核心代码指定一个负责人。各自使用 Git 工作树，集成后验证组合结果。 |
| Agent 中断怎么恢复？ | 保存检查点，记录执行位置和工具结果；如果文件已经写了但结果未保存，先核对真实文件或提交，再决定是否重做。 |
